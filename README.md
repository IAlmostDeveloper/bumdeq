# Бомждек

Бомждек (Bumdeq) - собранный из валявшегося под ногами мусора скалолазный тестер наподобие [Tindeq](https://tindeq.com/)

Устройство представляет собой s-образный датчик, подключенный к bluetooth модулю, с помощью которого с него снимаются измерения.

Измерения показываются на стороне Android приложения, которое подключается к устройству.
Пока что из замеров доступен только Critical Force (Критическая сила)
